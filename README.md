# 🏥 Hospital Appointment System

A responsive web-based hospital appointment booking interface that allows users to search for available doctors based on date, time slot, and specialization, and then book an appointment through an interactive booking flow.

## 📌 Overview

The Hospital Appointment System is a frontend project designed to simplify the process of finding available doctors and booking hospital appointments.

Users can:

- Select an appointment date
- Choose an available time slot
- Filter doctors by specialization
- View available doctors and their room numbers
- Select a doctor and book an appointment
- Enter a Patient ID or full name
- Receive an appointment confirmation

The project uses mock doctor data and simulated API behavior to demonstrate the complete appointment-booking user flow.

## ✨ Features

- 📅 Date selection with past-date restriction
- ⏰ Multiple appointment time slots
- 👨‍⚕️ Doctor availability filtering
- 🩺 Specialization-based search
- 🏥 Doctor room number display
- 📋 Appointment confirmation modal
- 👤 Patient ID / name input
- 💊 Hospital pharmacy location information
- 🔄 Loading state while searching
- ⚠️ Validation and error messages
- 📱 Responsive design for different screen sizes
